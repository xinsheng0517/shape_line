# 形状流水线 · Shape Line

一个纯前端的工厂建造小游戏：采集形状原料，用传送带、切割机、旋转机、混合机搭出产线，把目标形状送进中央枢纽。零依赖、单文件，**电脑与手机浏览器均可游玩**。

## 快速开始

| 方式 | 步骤 |
|---|---|
| 最简单 | 双击 `dist/shape-line.html`，用浏览器打开即玩（无需联网、无需安装） |
| 手机游玩 | 把 `dist/shape-line.html` 发送到手机，用浏览器打开 |
| 局域网分享 | 在本目录运行 `python -m http.server 8000`，其他设备访问 `http://<你的IP>:8000/dist/shape-line.html` |
| 上线部署 | 把 `dist/shape-line.html` 丢到任意静态托管即可 |

支持环境：任何现代浏览器（Chrome / Edge / Firefox / Safari，含手机版）。进度自动保存在浏览器本地（localStorage），无需账号。

## 四种模式

- **教程模式**：8 关循序渐进学会一切，推荐首次游玩从这里开始。
- **自由模式**：32×20 大图、随机目标、不限预算，交付即换新目标，随意搭建。
- **挑战模式**：C1、C2、C5、C6 使用梯形、圆形、星形三类原料进行双切与重组；C3、C4 保留原有预算与吞吐玩法。六关均可冲击三星。
- **每日挑战**：当天所有玩家同一道题（日期种子），180 秒限时 + 设备上限，比拼本地最佳。

## 操作

| 操作 | 电脑 | 手机 |
|---|---|---|
| 放置 / 拖拽连铺传送带 | 左键 / 左键按住拖动 | 单指点按 / 按住滑动 |
| 拆除 | 右键拖拽，或选「拆除」工具 | 选工具栏「拆除」后点按/滑动 |
| 旋转 | R | 工具栏 ⟳ 按钮 |
| 框选复制 / 粘贴 / 存蓝图 | B / Ctrl+V / S | ⬚ 按钮 / 点蓝图栏 / ✚ 按钮 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y | ↶ / ↷ 按钮 |
| 暂停 / 调速 | 空格 / `,` `.` | 顶栏「暂停」/「1x」按钮 |

技巧：传送带拖到已有带上会自动拐弯连成线；蓝图画好一段产线后可以整体复制粘贴，R 旋转、M 镜像；挑战关里粘贴蓝图同样受预算约束。任何机器都可直接拆除，包括载物、加工中、暂停或已通关时。拆除会清掉机器内物品并退还机器预算；撤销可恢复空机器，已清掉的物品不会复原。挑战关可使用「重置供料」重新开始本轮。

## 四瓣挑战玩法（C1 / C2 / C5 / C6）

三类原坯分别为 `T` 梯形、`C` 圆形、`S` 星形。完整原坯进入切割机时沿纵向中心线切成左右半块；半块再次进入切割机时沿横向高度中线切成四瓣。「1/4」表示四瓣结构位置，梯形各瓣不必等面积。切割机的自动档依据输入阶段选择切割方向，**每次入机只切一级**；也可在侧栏锁定纵切或横切。两个产物分别进入出口托盘；未接传送带时停在托盘，接通后继续运输。第二级切割需用外部传送带把半块送回同一台或另一台切割机。不同原料的上下两瓣可合成左右混合半块，再用同一类混合机合成指定完整产物。每台机器每次只处理一个物品或一对输入。

四关均提供 `T/C/S` 三个资源节点，进入关卡时没有预放机器和参考布线。C1、C5 初始缓存 3 个原坯、目标只需其中两种资源；C2、C6 初始缓存 6 个原坯、目标必须使用三种。缓存用尽后按需持续生成原料，不存在资源总量上限；下游堵塞时采集器会正常等待，通路恢复后继续出料。C1、C2 的机器不限量；C5、C6 最多放 3 台采集器、80 条传送带，其他机器不限量。挑战关自动供料，放好采集器与产线后即可生产；侧栏的「重置供料，保留布线」恢复本轮供料序号与进度。枢纽只接收目标卡显示的新完整产物。C4 是唯一保留「启动供料」按钮的关卡，倒计时从点击按钮后开始。

传送带不显示方向箭头；带面斜纹沿实际运行方向持续滚动，布线阶段也能辨认流向。

蓝图库位于右侧抽屉，可在浏览器本地保存，也可导入、导出专用 `.slbp.json` 文件。旧规则蓝图保留原件，迁移预览不会未经检查直接粘贴到新挑战。曾依赖切割机内部连续双切的蓝图仍可加载，但需要补接第二级切割的外部线路。资源使用轮廓、颜色和纹理共同区分。

## 开发者

发行版为 `dist/shape-line.html`（HTML+CSS+JS 单文件），源码在 `index.html` 和 `js/`。运行 `node test-petal-v3.js`、`node test-v3-runtime.js`、`node test-infinite-supply.js`、`node test-v3-integration.js` 验证新规则与持续供料；运行 `node test-headless.js`、`node test-c4-start.js`、`node test-blueprint-file.js` 验证旧玩法和蓝图。`node build.js` 重新打包离线单文件。
